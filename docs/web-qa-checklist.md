# 꼬북점 웹+앱 검수 요청 — 중복 · UX/UI · 결제 점검

> 목적: 새 버그 찾기가 아니라 **"덜어내야 할 것" 찾기**. 기능을 이것저것 붙이다 보니 비슷한 버튼·카드·문구가 여러 화면에 중복되거나, 동선이 필요 이상으로 복잡해진 곳이 있을 것 같습니다. 처음 쓰는 사람 입장에서 "어? 이거 두 개가 뭐가 다르지", "여기 왜 이렇게 복잡하지" 싶은 지점을 최대한 많이 모아주세요. 정답(어떻게 고칠지)까지는 필요 없고, **낯선 지점을 최대한 많이 수집**하는 게 목표입니다.

## 검수 환경

- **URL**: https://ggobuk.vercel.app — 프로덕션과 동일한 배포본이고, 네이티브 iOS/Android 앱도 이 URL을 그대로 불러오는 구조라 **웹에서 본 화면 = 앱에서 보이는 화면**입니다.
- **로그인**: 첫 화면 → "내 꼬북점 시작하기" → **"테스트 로그인 (익명)"** 버튼. 실계정/카카오 로그인 불필요.
- **권장 화면 크기**: 이 앱은 사실상 모바일 전용 UI라, 크롬 개발자도구의 기기 툴바(또는 실제 스마트폰 브라우저)로 **375~430px 폭**에서 봐주세요. 데스크톱 와이드 화면으로 보면 안 보이는 문제가 있을 수 있어 데스크톱에서도 1회만 훑어봐 주시면 됩니다.
- **주의**: 지금 베타 기간이라 `BETA_FREE_MODE`가 켜져 있어서 대부분 화면에서 "충전하기" 결제 버튼/페이월이 안 보이거나 무료로 통과됩니다. **결제 버튼이 안 보이는 건 버그 아님** — 대신 "충전 유도 카피가 몇 군데서 반복되는지"만 텍스트 레벨로 체크해주세요.

## 검수 포인트 A — 불필요한 중복

- **A-1. 같은 목적의 버튼/링크가 라벨만 다르게 여러 곳에 있는지.**
  예시로 이미 발견한 것: 홈 화면에 "내 카드 자세히 보기" / "내 사주 자세히 보기" / "오늘 하루 자세히 보기" 세 버튼이 붙어 있는데, 뒤의 둘은 실제로 같은 화면(`/shell`)으로 연결됩니다. 라벨만 보고 세 버튼의 차이가 바로 이해되는지 확인해주세요. 이런 패턴이 다른 화면에도 있는지 찾아주세요.
- **A-2. 같은 정보(카피/데이터)가 여러 화면에 그대로 반복되는지.**
  예시: "정사 일주" 소개문 + 해시태그 5개가 홈 히어로 카드 / 사주(등껍질) 탭 / 일주 공유카드 페이지, 세 곳에 동일하게 노출됩니다. 의도된 반복(정체성 강조용)인지, 그냥 정리가 안 된 것인지는 판단하지 않아도 되니 **"어디어디에 같은 내용이 나오는지"만 나열**해주세요.
- **A-3. 같은 기능으로 들어가는 입구가 몇 개인지.**
  예: "모드 선택"(페르소나 전환)이 모든 화면 우상단 플로팅 버튼으로 항상 떠 있고, 더보기 메뉴 안에도 같은 기능이 별도 행으로 있습니다. 입구가 여러 개인 것 자체는 나쁘지 않지만, 그중 안 쓰일 것 같거나 위치가 헷갈리는 입구가 있는지 봐주세요.
- **A-4. 배너/프로모 카드가 한 화면에 몇 개나 쌓여 있는지.**
  첫충전 배너, 시즌/생일 배너, 신규 환영 카드, 부적·웹툰 홍보 등이 홈이나 상점 화면에 동시에 여러 개 뜨는 경우가 있습니다. 한 화면에서 몇 개가 겹쳐 보이는지, 문구끼리 서로 비슷한 얘기를 반복하는지 체크해주세요.

## 검수 포인트 B — 복잡한 UX/UI

- **B-1. 홈에서 원하는 기능(오늘 운세 / 사주풀이 / 궁합 / 채팅)까지 몇 번 탭 하면 도달하는지.** 불필요하게 거쳐가는 화면이 있는지.
- **B-2. 레이아웃 겹침/잘림.**
  예시로 이미 발견한 것: 꼬북상점(`/more/pro`) 화면에서 하단에 고정된 "충전하기" 바가, 위쪽 스크롤 목록의 "대운 AI 해설 · 길일 찾기" 항목 일부를 가립니다. 이런 하단 고정 버튼이 있는 다른 화면들도 **끝까지 스크롤해서 가려지는 텍스트/버튼 없는지** 전수로 봐주세요.
- **B-3. 하단 탭바 근처 플로팅 요소가 탭바와 겹치거나 오탭을 유발하는지.** (예: 풀이 생성 상태를 보여주는 알약 모양 배지가 탭바 바로 위에 뜸)
- **B-4. 한 화면의 정보 밀도.** 카드/버튼/문단이 과하게 많아서 스크롤이 지나치게 긴 화면이 있는지.
- **B-5. 같은 아이콘·색이 화면마다 다른 의미로 쓰여서 헷갈리는 곳.**
- **B-6. 페르소나(꼬북이/도사/무당/보살) 전환 시 말투만 바뀌어야 하는데, 버튼 위치나 레이아웃까지 달라져서 일관성이 깨지는 곳이 있는지.**

## 검수 포인트 C — 결제(IAP) 확인 (앱에서만 가능, 웹 불가)

> 실제 스토어 결제(StoreKit/Play Billing)는 네이티브 SDK로만 트리거되기 때문에 브라우저에서는 재현이 안 됩니다. 아래는 실기기 앱(iOS는 TestFlight, Android는 Play 내부 테스트 트랙)으로 진행해주세요.

**준비물**
- iOS: TestFlight 최신 빌드 + **Apple Sandbox 테스터 계정** (TestFlight에서 구매 시 자동으로 샌드박스 결제창이 뜹니다)
- Android: Play Console **내부 테스트 트랙** 링크로 설치한 빌드 + **라이선스 테스터로 등록된 구글 계정** (결제창에 "테스트 카드, 청구되지 않음" 문구가 보이는지로 샌드박스 여부 확인)
- ⚠️ 반드시 샌드박스/테스트 계정으로 진행 — 실카드로 실결제하지 마세요.

**확인할 것**
1. 꼬북상점 화면의 상품명·가격이 App Store Connect / Play Console 등록 정보와 정확히 일치하는지 (단품·번들 전부)
2. 구매 버튼 → 네이티브 결제 시트(Face ID/지문 또는 Google 결제 확인창)까지 매끄럽게 뜨는지, 중간에 웹뷰가 끼어들거나 멈추는 곳은 없는지
3. 결제 완료 직후 꼬북알 잔액이 바로 반영되는지 (새로고침해야 보이는지도 체크)
4. 같은 상품을 연속으로 빠르게 두 번 탭했을 때 중복 결제되지 않는지
5. 결제 도중 취소(뒤로가기/스와이프)했을 때 에러 안내가 뜨고, 크레딧이 잘못 쌓이지 않는지
6. 앱 완전 종료 후 재실행했을 때 구매한 꼬북알 잔액이 유지되는지
7. **iOS·Android 각각 따로** 진행 — 한쪽 SDK에서만 나는 문제가 있을 수 있음
8. (실제 환불까지는 불필요) "결제 후 7일 이내 미사용분만 환불 가능" 문구가 결제 화면에 노출만 되는지 확인

**결과 보고**: 아래 "보고 형식"과 동일하되 유형은 **C(결제)**로 남겨주세요. 결제 시트 뜨는 타이밍이나 에러 순간은 스크린샷보다 **화면 녹화**가 훨씬 도움됩니다.
