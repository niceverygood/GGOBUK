# 꼬북점 서비스 검수 가이드 (직원용)

> **이 검수의 목적은 버그 찾기가 아닙니다.**
> 코드/기능 오류는 따로 자동 검수를 돌리고 있어요. 여러분께 부탁드리는 건
> **"실제로 써보니 어땠는가"** 딱 하나입니다.
>
> - 재미있었는지, 지루했는지
> - 사주 내용이 나랑 맞았는지, 뜬구름 같았는지
> - **"이런 기능도 있으면 좋겠다"** 싶은 게 뭐였는지 ← 제일 중요합니다
>
> 정답은 없습니다. 느낀 대로, 솔직하게, 냉정하게 적어주세요.
> 좋은 말보다 **"이래서 안 쓸 것 같다"** 가 훨씬 도움이 됩니다.
>
> **소요 시간**: 60~90분 (풀이 생성 대기 시간 포함)

---

## 0. 시작 전 준비

### 접속

- **주소**: https://ggobuk.vercel.app
- **꼭 휴대폰으로 봐주세요.** 모바일 전용으로 만든 앱이라 PC로 보면 어색합니다.
  (PC밖에 없다면 크롬 개발자도구 → 기기 툴바 → 폭 **390px** 정도로 맞춰주세요)
- **로그인**: 첫 화면 → `내 꼬북점 시작하기` → **카카오 로그인** 권장
  - 카카오가 부담스러우면 `테스트 로그인 (익명)` 도 됩니다. 단 이건 나중에 계정 복구가 안 되니
    한 번에 끝까지 봐주세요.

### 사주 정보는 반드시 "본인 것"으로

적중률을 봐야 하기 때문에 **자기 실제 생년월일**을 넣어주세요.
태어난 시간을 모르면 `시간을 모르겠어` 를 선택해도 정상 동작합니다.

### ⚠️ 미리 알아두실 것 (몰라서 당황하지 마시라고)

| 항목 | 내용 |
|---|---|
| **꼬북알** | 가입하면 30알을 드려요. 전체 풀이 1편에 5알, 채팅은 하루 5번 무료 후 1알씩. |
| **풀이 생성 시간** | "전체 풀이 받기"를 누르면 **40~50초** 걸립니다. 멈춘 게 아니니 기다려주세요. |
| **⚠️ 생년월일 수정 주의** | 내 정보에서 생년월일을 고치면 **이미 받은 풀이가 삭제됩니다.** 풀이를 다 읽고 나서 수정해주세요. |
| **"다시 풀어보기"** | 누르면 **5알이 또 나갑니다.** 확인창 없이 바로 나가니 주의. |
| **베타 무료** | 홈 아래에 "베타 기간 — 모든 풀이 무료" 배지가 보이면 꼬북알이 안 닳는 상태입니다. 그럼 마음껏 눌러보셔도 돼요. |

### 이미 알고 있는 문제 (또 안 적으셔도 됩니다)

- 처음 들어갔을 때 **"오늘의 운세를 가져오는 중이야…"** 에서 안 넘어갈 수 있어요.
  → **새로고침 한 번** 하면 나옵니다. 이건 저희가 이미 알고 고치는 중입니다.
- 첫 화면(로그인 전 소개 페이지)에 **궁합·대운·택일** 같은 메뉴가 보이는데 실제 앱에는 없습니다.
  → 이것도 인지하고 있습니다. (다만 **"기대했는데 없어서 어땠는지"** 는 적어주시면 좋아요!)

## 1. 첫인상 (5분)

로그인하고 생년월일을 넣은 직후, **아직 아무것도 눌러보기 전에** 답해주세요.

- **Q1.** 이 앱이 뭐 하는 앱인지 3초 안에 이해됐나요? (예 / 아니오 — 아니라면 뭐가 헷갈렸나요)
- **Q2.** 첫 화면을 봤을 때 가장 먼저 눈이 간 곳은 어디였나요?
- **Q3.** "다음에 뭘 눌러야 하지?" 가 명확했나요? 아니면 뭘 해야 할지 몰라 잠깐 멈췄나요?
- **Q4.** 디자인 첫인상을 한 단어로. (예: 귀엽다 / 촌스럽다 / 깔끔하다 / 정신없다 / 유치하다 …)
- **Q5.** 앱 이름이 "꼬북점"인데, 이름과 화면 분위기가 어울리나요?

**첫인상 점수: ⭐ / 5**

## 2. 내 사주 캐릭터 — "일주 카드" (10분)

홈 맨 위에 있는 `○○일주` 카드입니다. 저희가 이 앱의 **간판**으로 생각하는 화면이에요.

- **Q6.** 카드에 적힌 한 줄 설명(예: "겉은 부드럽고 속은 자기 자리가 분명")과 해시태그가
  **본인 성격과 맞나요?** (전혀 아니다 1 ~ 소름 5)
- **Q7.** 이 카드, **친구한테 보내고 싶은 마음이 드나요?**
  - 실제로 `친구한테 보내기` 를 눌러보세요. 눌렀을 때 뭐가 나오는지, 그게 기대한 거였는지 적어주세요.
  - 안 보내고 싶다면 **왜** 안 보내고 싶은지가 더 중요합니다. (부끄러워서? 재미없어서? 예뻐 보이지 않아서?)
- **Q8.** `내 카드 자세히 보기` 도 눌러보세요. 홈 카드랑 **내용이 겹친다**고 느꼈나요?
- **Q9.** MBTI처럼 "나는 ○○일주야" 라고 남한테 말할 만한가요? 그럴 만큼 **캐릭터가 매력적인가요?**

> 💡 참고: 요즘 MBTI·퍼스널컬러처럼 "내 유형" 을 공유하는 게 유행이라, 저희는 일주(60갑자)를
> 그 자리에 놓으려 하고 있어요. 그 의도가 실제로 먹히는지를 봐주시면 됩니다.

**일주 카드 점수: ⭐ / 5**

## 3. 오늘의 운세 (5분)

홈 가운데 점수(예: 52점)와 "오늘의 한 줄" 이 있는 카드입니다.

- **Q10.** 점수(0~100)를 봤을 때 **납득이 되나요?** 아니면 "이 점수 뭐 기준이지?" 싶나요?
- **Q11.** "오늘의 한 줄" 이 **오늘 내 상황이랑 맞나요?** 아니면 아무 날에나 해도 되는 말 같나요?
- **Q12.** 추천 행동(✓ 표시된 것들)이 **진짜 해볼 만한** 내용인가요? 뻔한가요?
- **Q13.** **이거 하나 보려고 내일 또 앱을 열 것 같나요?** (솔직하게)
  - 아니라면, 매일 열게 만들려면 뭐가 더 있어야 할까요?

**오늘의 운세 점수: ⭐ / 5**

## 4. 전체 풀이 — 이 앱의 핵심 상품 (25분)

`내 사주 풀이` → `전체 풀이 받기` (5꼬북알, 40~50초 소요)

> 이게 **유일한 유료 상품**입니다. 여기가 별로면 앱 전체가 별로인 거예요.
> **정독**해주세요. 대충 스크롤하지 마시고요.

### 4-1. 기다리는 동안

- **Q14.** 40~50초 기다리는 게 **길게 느껴졌나요?** 로딩 화면(꼬북이가 단계별로 뭘 하는지 보여주는 것)이
  기다림을 견딜 만하게 해줬나요? 아니면 그냥 답답했나요?

### 4-2. 적중률 — ⭐ 가장 중요한 부분

읽으면서 아래 3가지를 **문장 그대로 복사해서** 적어주세요. 요약하지 마시고 원문 그대로요.

**(가) "어, 이거 완전 나잖아" 싶었던 문장 — 3개**
```
1.
2.
3.
```

**(나) "이건 전혀 아닌데?" 싶었던 문장 — 2개**
```
1.
2.
```

**(다) "이건 누구한테나 해당되는 말 아닌가?" 싶었던 문장 — 2개**
```
1.
2.
```

> 💡 (다)가 특히 중요합니다. 사주 앱이 망하는 가장 흔한 이유가 **"누구에게나 맞는 말"** 만 하는 거예요.
> (다)에 적을 게 많을수록 저희 프롬프트가 잘못된 겁니다. 가차없이 적어주세요.

- **Q15.** 전체적으로 **체감 적중률 몇 %** 정도인가요? (숫자로)
- **Q16.** 읽고 나서 **"돈 주고 볼 만했다"** 는 생각이 드나요? 5알(≈1,500원 상당)의 값을 하나요?

### 4-3. 읽는 경험

- **Q17.** 분량이 적당한가요? (너무 길다 / 적당 / 너무 짧다)
- **Q18.** 맨 위 "한눈에" 요약 카드(🔑 키워드 / ✅ 이렇게 해봐 / ⚠️ 이건 조심)가 **도움이 됐나요?**
- **Q19.** 6개 섹션(나라는 사람 / 타고난 강점 / 조심할 그늘 / 일과 돈 / 사랑과 관계 / 지금의 흐름) 중
  - **제일 재밌게 읽은 섹션**은?
  - **제일 시시했던 섹션**은?
  - **없어서 아쉬운 섹션**이 있다면?
- **Q20.** 반말 친구 말투("~야", "~거든")가 **편했나요, 가벼웠나요?**
  진지한 상담을 원할 때도 이 말투가 괜찮을까요?
- **Q21.** 읽다가 **한자**(丁巳 같은 것)나 **어려운 사주 용어**(비견, 용신, 격국 등)가 튀어나온 적 있나요?
  있으면 그 문장을 그대로 적어주세요. (일반인이 몰라도 되게 만드는 게 목표라 이건 오류입니다)
- **Q22.** 문장이 **중간에 뚝 끊긴** 곳이 있었나요? 마지막이 "오늘부터 하나:" 로 잘 끝났나요?

**전체 풀이 점수: ⭐ / 5**

## 5. 꼬북이 채팅 (15분)

`꼬북이랑 대화` — 최소 **8번 이상** 대화해주세요. (5번까지 무료, 그 뒤는 1알씩)

아래 3가지는 꼭 물어봐주세요:

1. 미리 준비된 버튼(연애중 / 취업 준비 등) 중 하나 누르기
2. **본인의 진짜 고민**을 자유롭게 물어보기 (구체적일수록 좋아요)
3. **사주와 전혀 상관없는 질문** 하나 (예: "오늘 점심 뭐 먹지?", "너 AI야?")

- **Q23.** 답변이 **내 사주를 알고 하는 말** 같나요? 아니면 그냥 일반적인 상담 챗봇 같나요?
- **Q24.** 꼬북이 **캐릭터가 느껴지나요?** (귀엽다 / 친근하다 / 아무 성격 없다 / 어색하다)
- **Q25.** "너 AI야?" 라고 물었을 때 뭐라고 답하던가요? 캐릭터가 깨졌나요?
- **Q26.** 답변에 **이상한 기호**(`**굵게**`, `##`, `- ` 같은 것)가 그대로 보인 적 있나요?
- **Q27.** 대화가 길어졌을 때 **앞에서 한 얘기를 기억**하던가요?
- **Q28.** 5번째 질문 넘어갈 때 **"이제부터 유료입니다" 같은 안내가 있었나요?** 없었다면 어떤 기분이 드나요?
- **Q29.** 이 채팅, **돈 내고 계속할 만한가요?** 어떤 상황이면 돈 내고 쓸 것 같나요?

**채팅 점수: ⭐ / 5**

## 8. 남에게 보여주기 (10분) — 가능하면 꼭

**본인 말고 다른 사람 1~2명**에게 폰을 넘겨서 직접 만져보게 해주세요.
(가족·친구·옆자리 동료 아무나. 사주에 관심 없는 사람일수록 좋습니다)
